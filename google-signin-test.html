ทดสอบ Google Sign-In รายบุคคล

กลุ่มงานบริหารงานวิชาการ โรงเรียนเทศบาล ๓ (วัดท่ามะปราง)

ทดสอบการเชื่อมต่อ Google เท่านั้น

หน้านี้ทดสอบเฉพาะการทำงานของ Google Identity Services ในเบราว์เซอร์ ยังไม่ใช่การเข้าสู่ระบบทะเบียนจริง และไม่อนุญาตให้ออกเลขหนังสือ ดูทะเบียน หรือแก้ไขข้อมูล

กำลังเตรียม Google Sign-In...

ไม่แสดง ไม่บันทึก และไม่ส่ง Google ID Token ไปยังเซิร์ฟเวอร์ของโรงเรียนหรือ GitHub

การทดสอบที่ยังต้องทำ

หลัง Google ส่งผลเข้าสู่เบราว์เซอร์แล้ว ต้องตรวจลายเซ็น ID Token และผูก Google Account ID (sub) กับ USERS → PersonnelID ใน School Core โดยผู้มีอำนาจอนุมัติ จากนั้นจึงเปิดการบันทึก Login Audit ฝั่งเซิร์ฟเวอร์และสิทธิ์การใช้งานจริง

กลับสู่ระบบทะเบียน Public รุ่น v0.5.10 (ใช้งานจริง)
